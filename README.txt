# 💕 Página romántica para tu novia

## Cómo usarla

1. Abre la carpeta en VS Code.
2. Abre `index.html` en el navegador.
3. Reemplaza las imágenes dentro de:
   `assets/images/`
4. Coloca tu canción MP3 en:
   `assets/music/cancion.mp3`
5. Abre `js/script.js` y cambia:
   `const fechaInicio = "2025-01-01T00:00:00";`
   por la fecha que quieras usar en el contador.

## Fotos

Reemplaza estos archivos por tus fotos:
- foto1.jpg
- foto2.jpg
- foto3.jpg
- foto4.jpg
- foto5.jpg
- foto6.jpg
- foto7.jpg
- foto8.jpg
- foto9.jpg
- foto10.jpg

Si una imagen no existe, el navegador mostrará un espacio vacío. Puedes usar cualquier JPG/PNG, manteniendo los mismos nombres.

## Música

Coloca tu archivo como:
`assets/music/cancion.mp3`

La música se activa al pulsar el botón 🎵, porque los navegadores normalmente bloquean el autoplay con sonido.

## Personalización

Puedes editar directamente los textos de `index.html`: nombre, recuerdos, carta, frases y fechas.
